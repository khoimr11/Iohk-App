# Tiệm Phim

App chỉnh ảnh kiểu film chạy trên trình duyệt, với preset Nhật Bản, Hong Kong, retro và vintage. Có thêm hạt film, halation, bloom, light leak và in ngày.

Ảnh được xử lý ngay trên máy (WebGL), không upload đi đâu.

## Chạy
Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
